
# Healthcare Analytics Dashboard (SQL + Excel)

This project presents a healthcare analytics dashboard built using **MySQL and Microsoft Excel** to analyze patient data and treatment-related insights.

## Tools Used
- MySQL  
- Microsoft Excel  

## Key Features
- KPI analysis: Total Patients, Avg Length of Stay, Total Treatment Cost  
- Department & insurance-wise cost analysis  
- Outcome-based performance insights  
- Monthly admission trends using derived date logic  
- SQL views and window functions for department ranking  
- Interactive Excel dashboard with charts and slicers  

## Dataset
- Synthetic dataset created for learning and portfolio purposes  
- No real patient data used  

## Files
- SQL scripts for analysis  
- Excel dashboard file  
- Dashboard screenshot for quick preview  

This project demonstrates practical **SQL querying, data analysis, and Excel dashboarding skills**.
